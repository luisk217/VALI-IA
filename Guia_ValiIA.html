Tu prototipo está preparado

El paquete contiene la aplicación local, tres bases ficticias, ocho reglas, pruebas ejecutables, reportes y el material para presentar un avance en sinergIA.

Esta página es la guía. La aplicación se abre en tu equipo al ejecutar el comando de inicio.

1. Instalar en Windows

  1. Extrae Vali-IA_prototipo.zip. Abre la carpeta Vali-IA que contiene app.py.
  2. Instala Python 3.12 desde python.org, si no lo tienes. Marca Add python.exe to PATH.
  3. En la barra de direcciones del Explorador escribe cmd y pulsa Enter. Ejecuta los comandos siguientes, uno por uno:
py -3.12 --version
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m streamlit run app.py

Comprueban Python, crean un entorno aislado, instalan las dependencias e inician Vali-IA. Solo la instalación necesita internet. Si py no existe, comprueba python --version y usa python -m venv .venv con Python 3.12.

Abre http://localhost:8501. Mantén la terminal abierta. Para cerrar, pulsa Ctrl+C en ella. La próxima vez puedes hacer doble clic en iniciar_windows.bat.

2. Hacer tu primera revisión

  1. En Bases de demostración, selecciona Con errores conocidos.
  2. Pulsa Validar información.
  3. Comprueba: 200 registros, 18 con error y 91 % sin errores.
  4. En Hallazgos, revisa el responsable vacío (H001), el ID repetido (H002/H003) y la diferencia provisional de totales (H022).
  5. En Conciliación observa los grupos no comparables y las cuatro filas no agrupables.
  6. Descarga el reporte completo en Excel.

24 alertas de error no significa 24 registros con error. Hay 18 alertas en Registros y 6 en el resumen. Se suman 3 advertencias y 1 pendiente informativo: 28 hallazgos en total.

Prueba también Excepciones válidas: debe mostrar 100 % sin errores y tres pendientes informativos. Repetir un animal en distintas actividades es válido. Cambiar de base borra los resultados anteriores; vuelve a pulsar Validar.

3. Explicar los hallazgos con IA

  1. Abre la pestaña Informe e IA y descarga el paquete para IA.
  2. Extrae el ZIP. Adjunta resultados_validacion.json en tu asistente de IA.
  3. Copia el contenido de prompt_para_IA.txt como instrucción.
  4. Revisa las cifras y referencias del borrador. Comprueba que respeta los totales provisionales y no inventa causas.

Esta transferencia es manual. La aplicación no llama a una API. El resumen por reglas usa una plantilla y no se presenta como IA. En docs/ejemplo_borrador_IA.md tienes un ejemplo redactado por el asistente durante el desarrollo; es un texto fijo, no una generación automática de la aplicación.

6. Documentación incluida

README.md contiene la instalación completa, interpretación, errores frecuentes y fuentes técnicas. docs/diccionario_y_reglas.xlsx explica los campos y reglas. docs/decisiones.md documenta el alcance.

En docs/medicion_piloto.xlsx registra la revisión manual y el tiempo asistido completo. Las casillas están vacías para que anotes mediciones reales. Total asistido = preparación + procesamiento + revisión humana + IA. El ahorro se calcula solo después de medir ambos procesos.

Cómo se calculan los totales

Se cuentan todas las filas con fecha, especie y actividad válidas, incluidos los duplicados. Cualquier error en Registros hace provisionales los recuentos. Las filas no agrupables se enumeran aparte. Una combinación del resumen ausente, duplicada o inválida no se compara. Ningún vacío se transforma en cero.

Requisitos del Excel de entrada

Hojas Registros, Resumen_mensual, Catalogos y Diccionario. Aviso en fila 1, contexto en fila 2, cabeceras en fila 3 y datos desde fila 4. Valores sin fórmulas. Máximo 5 MB. Categorías y corte fijos para esta demostración. Usa solo datos ficticios.
